# 早餐採買清單

一頁靜態網頁，把大家報的早餐依「哪間店買得到」拆開統計，現場逐項打勾清點。
還沒點的人隨時可以自己加進去，不用改程式。

網址（GitHub Pages）：`https://<帳號>.github.io/bibi-birthday/breakfast/`

## 怎麼加新的點餐

把 LINE 傳來的字直接貼進頁面上方的框，一行一個人，按「加入清單」：

```
王大明：御飯團＋熱奶茶
李小美：燒餅夾蛋、冰豆漿 x2
林伯伯：水煎包 兩個、紅茶冰
```

網頁會自己處理：

- **對到菜單品項**，順便認得常見寫法（御飯團＝御飯糰、起士蛋餅＝起司蛋餅）。
- **判斷是哪間店買**，蛋餅燒餅類歸德記，拿鐵美式咖啡一律歸 7-11。
- **抓出冰熱、糖度、數量**（`x2`、`兩個`、`熱`、`無糖` 都認得），冰的熱的會分開列，方便跟老闆點。
- **重算份數和金額**，三張店家卡片、個人對照表、待確認事項全部跟著更新。

認不出來的品項會標紅字，在「個人對照」用下拉選單指定就好；或打開「用選單一項一項加」直接選。
兩間店都有的品項（奶茶、紅茶、米漿、蘿蔔糕）後面會出現下拉，可以自己換到另一間。

其他按鈕：**複製整份清單**把統計轉成文字，可以貼回 LINE；**回到原始 8 人**清掉後來加的。

點餐內容和打勾狀態存在瀏覽器（localStorage），換手機或清掉瀏覽資料就會回到原始 8 人。
只有自己那支手機看得到，不是多人共用；要大家各自填、即時同步的話，得像 `care/` 那樣接
Google Apps Script 和試算表。

## 手機上怎麼用

主要就是拿手機在店門口用，所以版面以手機為準：

- 最上面有一條會跟著捲動的列，可以直接跳到「無名店／德記／7-11」，右邊顯示「已買 x / y」。
- 「新增點餐」在手機上預設收起來，一開頁面就直接看到要買什麼，要加人再點開。
- 「個人對照」在窄螢幕會變成一人一張卡，不用左右滑。
- 輸入框固定 16px，iPhone 點下去不會自動放大；勾選框和按鈕都放大到好按的尺寸。
- 深色模式跟著手機設定走。

## 目前的三個採買點

| 店家 | 說明 |
|---|---|
| 無名早餐店（`menus/stall-*.jpg`） | 飯糰、三明治、捲餅、碗粿、壽司、水煎包、飲品 |
| 德記（`menus/deji-menu.jpg`） | 蛋餅、燒餅、包子類只有這間有 |
| 7-11 | 咖啡，統一大杯 |

**永正**（御飯糰＋起司蛋餅）和**正嘉**（燒餅夾蛋＋豆米漿）是跨店單，兩間都要跑到才齊。

## 要改程式的地方

全部在 `index.html` 的 `<script>` 裡：

- `SHOPS`：三個採買點的名稱與說明。
- `MENU`：菜單。`price: null` 表示價目表看不清楚，只算份數不算錢（德記整間都是這樣，
  哪天對到價格就把數字填上）。`alias` 是這個品項認得的寫法，`alt` 是「兩間店都有」時的另一間。
- `seed()`：原始 8 人的點餐，「回到原始」還原的就是這一份。

`menus/` 放的是現場拍的菜單照片，改店家或品項時一併更新。
