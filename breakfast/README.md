# 早餐採買清單

一頁靜態網頁，把大家報的早餐依「哪間店買得到」拆開統計，現場可以逐項打勾清點。
打勾狀態存在瀏覽器裡，重新整理不會掉。

網址（GitHub Pages）：`https://<帳號>.github.io/bibi-birthday/breakfast/`

## 三個採買點

| 店家 | 份數 | 說明 |
|---|---|---|
| 無名早餐店（`menus/stall-*.jpg`） | 12 | 飯糰、三明治、捲餅、碗粿、壽司、水煎包、飲品 |
| 德記（`menus/deji-menu.jpg`） | 2 | 蛋餅、燒餅類只有這間有 |
| 7-11 | 2 | 熱拿鐵大杯，咖啡一律超商買 |

**永正**（御飯糰＋起司蛋餅）和**正嘉**（燒餅夾蛋＋豆米漿）是跨店單，兩間都要跑到才齊。

## 待確認

1. 正嘉的豆米漿冰或熱（訂單上沒寫）。
2. 明華的熱奶茶兩間都有，目前歸在無名店（和他的三明治同一間）。
3. 秋滿的鮮奶茶要交代「熱、無糖」。

## 要改內容

直接編輯 `index.html`：

- 品項與數量在三張 `.store` 卡片的 `ul.items` 裡，每一列是一個 `label.row`。
- 個人對照在 `個人對照` 那個 `<table>`。
- 頁首的「總份數／採買點」是寫死的數字，改品項時記得一起改。
- 金額估算寫在頁尾，依無名店牆上價目表；德記照片字跡模糊，價格沒列入。

`menus/` 放的是現場拍的菜單照片，改店家或品項時一併更新。
