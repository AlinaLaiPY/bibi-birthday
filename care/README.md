# 台中長照接送速查 — 家人共用版

一個放在 GitHub Pages 的手機網頁，資料存在你自己的 Google 試算表。
家人各自用 iPhone 開同一個網址，**筆記共用、狀態即時同步**，而且每個人
搜尋了什麼、打給了哪一家，都會自動記進試算表。

```
iPhone（Safari／主畫面）
      │
      ▼
GitHub Pages  care/index.html      ← 純靜態網頁，沒有伺服器
      │  JSONP（免 CORS 設定）
      ▼
Google Apps Script  /exec          ← care/apps-script/Code.gs
      │
      ▼
Google 試算表
      ├─ 「紀錄」    每家單位的狀態／星號／筆記（家人共用一份）
      └─ 「使用紀錄」誰、何時、搜尋什麼、打給誰
```

沒有設定雲端時，網頁一樣能用，只是紀錄只留在那支手機上。

---

## 步驟一：建立雲端試算表（約 5 分鐘）

1. 到 [sheets.new](https://sheets.new) 開一份新試算表，取名例如「長照接送 家人共用」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 把編輯器裡原本的 `function myFunction() {}` 全部刪掉，貼上
   [`apps-script/Code.gs`](apps-script/Code.gs) 的全部內容。
4. 改第 20 行左右的通關碼，改成只有家人知道的字串：
   ```js
   var TOKEN = 'bibi2026';   // ← 改成自己的
   ```
5. 存檔（💾）。右上角 **部署 → 新增部署作業**：
   - 類型：齒輪 → **網頁應用程式**
   - 說明：隨便填，例如「v1」
   - **執行身分：我自己**
   - **誰可以存取：所有人**　← 一定要選這個，家人才不用登入 Google
6. 按「部署」，第一次會要求授權：選你的 Google 帳號 →「進階」→
   「前往（專案名稱）」→「允許」。
7. 複製最後出現的 **網頁應用程式網址**，長得像：
   ```
   https://script.google.com/macros/s/AKfycb.....................ID/exec
   ```

> ⚠️ 之後只要改動 `Code.gs`，都要再做一次 **部署 → 管理部署作業 → 編輯（鉛筆）→
> 版本改成「新版本」→ 部署**，網址不會變，但改動才會生效。

## 步驟二：把網頁放上 GitHub Pages

1. 這個 repo 的 **Settings → Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 等一兩分鐘，網址就是：
   ```
   https://alinalaipy.github.io/bibi-birthday/care/
   ```

## 步驟三：設定並邀請家人

1. 用 Safari 開上面的網址，右上角點 **「本機模式」** 那顆膠囊。
2. 貼上步驟一的 `/exec` 網址、填入通關碼，按 **測試連線** —— 出現
   「連線成功」就好了。
3. 填 **我是誰**（例如「阿美」），家人動態才看得出來是誰做的。
4. 按 **複製家人邀請連結**，用 LINE 傳給家人。連結長這樣：
   ```
   https://alinalaipy.github.io/bibi-birthday/care/?api=...&t=...
   ```
   家人一點開就自動設定好，只要再填自己的名字。
5. 每個人都在 Safari 裡 **分享 → 加入主畫面**，之後像 App 一樣按一下就開。

## 常見問題

**手機顯示「連線失敗」**
- 部署時「誰可以存取」沒有選 **所有人** —— 最常見的原因。
- 通關碼跟 `Code.gs` 裡的 `TOKEN` 不一樣。
- 網址結尾不是 `/exec`（`/dev` 只有你自己登入時能用）。

**改了 Code.gs 卻沒反應** → 要重新「部署新版本」，見步驟一的提醒。

**沒網路的時候？** 網頁照常能查、能寫筆記，變更會排隊，回到有網路時自動補送。
右上角膠囊會顯示還有幾筆等著上傳。

**兩個人同時改同一家？** 以「後改的」為準，較舊的那筆會被雲端上的新版本蓋掉，
手機上會自動換成新的內容。

**隱私** 這個 Apps Script 是「知道網址 + 通關碼的人都能讀寫」。它不是嚴謹的權限
控管，只擋隨手亂試的人，所以邀請連結請只在家人群組裡傳。試算表本身仍然只有
你（和你分享的人）看得到。

**要換一份試算表** → 在新試算表重做步驟一，把新網址貼進網頁設定即可。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 整個網頁（名單資料、搜尋、紀錄、同步都在裡面，沒有相依套件） |
| `apps-script/Code.gs` | 貼到 Google Apps Script 的後端 |

名單資料是 114–116 年長期照顧服務特約單位一覽表（臺中市全市）裡
「交通接送服務及社區式服務交通接送（DA01 及 BD03）」的 39 家單位。
其中序號 **667** 的服務區域、序號 **184** 的交通接送電話在來源表格被裁切，
網頁上會標示「⚠ 需確認」。
